# Каба гайда — Android

Помощно приложение за начинаещи гайдари (Kotlin + Jetpack Compose, светла тема).

**Екрани**
- **Ручило** — вид гайда (каба/джура), калибриране на ручилото за 4 s, неутрални интервали (¾ тон).
- **Тунер** — коя стъпка свириш спрямо тониката (I, Г2, н3, 5…) и с колко цента се отклонява. Тониката, квинтата и октавата съвпадат с хармоници на ручилото; приложението ги разпознава правилно, вместо да ги „изтрие“.
- **Духане** — графика на тона на ручилото за последните 15 s, оценка 0–100 за равно налягане в меха.

## Изтегляне

**[⬇ Изтегли APK (последна версия)](https://github.com/waitingboy-collab/kaba-gaida-android/releases/latest)**

1. На телефона отвори линка и свали `KabaGaida-<версия>.apk` от раздела **Assets**.
2. Отвори файла. Ако Android попита — разреши „Инсталиране от неизвестни източници“ за браузъра.
3. При първото пускане разреши микрофона.

Версия за Windows: [kaba-gaida](https://github.com/waitingboy-collab/kaba-gaida).

## Компилиране

1. Отвори папката `KabaGaidaAndroid` в **Android Studio** (Ladybug 2024.2 или по-нов). Gradle sync ще свали всичко.
2. Телефон с включено USB отстраняване на грешки → **Run ▶**.
3. Само APK: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Файлът е в `app/build/outputs/apk/debug/app-debug.apk`.

Ако Android Studio предложи по-нови версии на AGP/Kotlin/Compose — може да ги приемеш.

Минимум Android 8.0 (API 26).

## Тестове

`app/src/test/.../CoreTest.kt` — десен клик → **Run 'CoreTest'**. Пуска 37 синтетични теста на анализа (симулирана каба гайда с ручило на Ре2): точност на тунера, ноти върху хармоници на ручилото, само ручило без фалшиви ноти, калибриране, джура гайда.

```
app/src/main/java/bg/rado/kabagaida/
  core/       чист Kotlin, без Android — FFT, YIN, калибриране, разпознаване, равномерност
  audio/      MicCapture — AudioRecord (UNPROCESSED/VOICE_RECOGNITION, 48 kHz)
  ui/         Compose екрани, тема, тунер, графика
  KabaViewModel.kt, MainActivity.kt
```

## Как работи разпознаването

1. При калибриране записва честотата на ручилото (YIN) и амплитудата на всеки негов хармоник.
2. На живо следи ручилото по хармониците под гайдуницата (за каба: 1–3) — оттам идват налягането и силата.
3. Изважда очакваното ручило от спектъра и търси гайдуницата по сумата на хармониците ѝ.
4. Точна честота: напасване на синусоиди в спектъра. Когато нотата е върху хармоник на ручилото, двата тона се напасват заедно с позната амплитуда на ручилото.
5. Показанието се изглажда с медиана от 5 кадъра (~0.2 s).
